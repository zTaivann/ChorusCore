# ChorusCore

A modular core for Paper servers: homes, warps, spawn, teleport requests, an economy of its
own, mail, private messages, sign shops, chest shops, staff tools, item tools, kits, world
controls and the usual utilities. 138 commands across 14 modules, every one of them
switchable, priced, restricted to the worlds you choose and themed from its own config file.

One jar runs on **1.18.2 through 26.2**, on Paper and on Folia.

## Documentation

Everything — installation, configuration, every command, every permission, the API and the
importers — is in the wiki:

**https://chorusdev.lat/wiki/choruscore**
