# Everything a player might want to look up, in chapters: /info rules, /info
# commands, and so on. /info on its own shows what is below and lists the rest.
#
# Same rules as motd.txt. A line like "#rules" opens a chapter and a second word
# on it is the permission needed to read that chapter, as on "#staff" below. A
# "#" followed by a space is a note to you and is never shown.
#
# Nine lines fill a page and the rest go on the next one, reached with
# /info <chapter> 2.
